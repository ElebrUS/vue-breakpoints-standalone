# Security policy

## Supported versions

Security fixes are applied to the latest published version.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Until a dedicated security contact is configured, report it privately to **YOUR SECURITY CONTACT** with a description, impact, and reproduction steps.

You should receive an acknowledgement within 7 days. The maintainer will coordinate a fix and disclosure timeline with you.

Before publishing, replace the placeholder contact with a monitored email address or GitHub private vulnerability-reporting link.
